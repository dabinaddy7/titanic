## 3. 📝 오늘 새로 배운 핵심 메서드 (Methods)

### ① `multiple='fill'` & `ax.yaxis.set_major_formatter()`
> y축의 단위를 '개수(Count)'가 아닌 **'비율(100%)'**로 통일하여 그룹 간 편차를 한눈에 비교하는 테크닉

```python
import matplotlib.ticker as mtick

# multiple='fill'로 설정하여 모든 막대 높이를 100%로 고정
ax = sns.histplot(data=df, x='fare_log', hue='survived', multiple='fill', bins=15)

# y축의 소수점(0.0 ~ 1.0) 눈금을 깔끔한 퍼센트(%) 옷으로 갈아입히는 메서드
ax.yaxis.set_major_formatter(mtick.PercentFormatter(1.0))
```

### ② `ax.containers` & `ax.bar_label()`
> 하드코딩 없이 그래프 내 모든 막대의 끝자리에 실제 데이터 수치(명수) 스티커를 자동으로 붙여주는 기능

```python
# ax.containers 보관함에 담긴 '사망자 막대 묶음'과 '생존자 막대 묶음'을 돌면서 작업
for container in ax.containers:
    # 지정한 막대 끝(edge)에 정수(%d) 형태로 3픽셀만큼 여백(padding)을 두고 숫자를 출력
    ax.bar_label(container, fmt='%d', label_type='edge', padding=3)
```

### ③ 디자인 커스텀 및 글자 겹침 해결
* **`plt.xticks(rotation=30, ha='right')`**
  * x축 레이블 텍스트가 길 때 글자가 서로 겹치지 않도록 30도 회전시키고 오른쪽 정렬하는 실무 필수 옵션.
* **`plt.plot(..., marker='o', linestyle='--')`**
  * 선 그래프에서 데이터 지점을 표시하는 마커 모양과 대시(점선) 스타일을 지정하여 가독성을 높임.
* **`plt.tight_layout()`**
  * 그래프의 제목이나 축 레이블이 여백 부족으로 잘리는 현상을 방지하는 자동 여백 최적화 매직 명령어.
