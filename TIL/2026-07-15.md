## 🙋‍♂️ 내가 품었던 의문들과 해결 과정

### 🔍 의문 1. 큰 수의 parch 부모/자식 데이터에서 왜 아이들은 안 보이고 40대만 보일까?
* **원인 분석:** parch 기준으로 내림차순 정렬을 했을 때 생긴 데이터의 구조적 특징이었다.
  * 40대 부모는 자녀가 많으므로 parch 값이 5, 6, 9 등으로 매우 크게 잡힌다.
  * 반면, 그 자녀들은 부모가 아무리 많아봐야 최대 2명이므로 parch가 2 이하로 기록된다.
  * 따라서 큰 수 위주로 정렬하면 "자식을 많이 데리고 탄 부모 세대"만 상단에 노출되는 착시가 있었던 것을 규명했다.

### 🔍 의문 2. 가족 수(family_size)가 5명 이상인 대가족은 왜 생존율이 급감할까? 혹시 3등석이라서?
* **가설:** 대가족은 대부분 요금이 저렴한 3등석에 탑승했을 것이며, 이것이 생존율에 결정적 영향을 미쳤을 것이다.
* **시각화 검증:** sns.barplot에 hue='pclass' 옵션을 적용하여 분석했다.
  * **결과:** 가족 수가 7, 8, 11명인 초대형 대가족 구역에는 1, 2등석 승객이 단 한 명도 없었다. (오직 3등석만 존재)
  * pd.crosstab을 통해 실제 탑승객 수(머릿수)를 교차 표로 만들어 교차 검증한 결과, 대가족의 비극 뒤에는 3등석의 그림자가 짙게 깔려 있음을 숫자로 명백히 증명했다.

### 🔍 의문 3. 시각화에서 4, 5, 6인 가족의 생존율이 역전되는 것처럼 보이는 이유는?
* **원인 분석:** 표본의 크기(Sample Size)가 너무 작아서 생긴 통계적 왜곡이었다.
  * 그래프에 표시된 긴 오차 막대(Error Bar)가 경고하듯, 해당 그룹의 1, 2등석 탑승객은 단 몇 명 수준에 불과했다.
  * 표본이 극단적으로 적으면 한두 명의 생존 여부에 따라 생존율이 80%~100%로 요동치기 때문에 발생한 착시임을 알아냈다.

### 🔍 의문 4. 나이를 범주화할 때 elif 조건문에서 굳이 이상(>=) 조건을 중복해서 넣어야 할까?
* **코드 효율화:** elif는 앞선 if 조건의 부정(False)을 이미 전제로 깔고 간다. 
* 불필요한 연산을 줄이기 위해 조건문의 범위를 중복 없이 순차적으로 걷어내는 '초고율 다이어트 조건문'을 직접 설계하여 반영했다.
* 최적화 코드 예시:
  def get_age_group(age):
      if pd.isna(age): return 'Unknown'
      if age < 15: return 'Child'
      elif age < 35: return 'Young'
      elif age < 60: return 'Middle'
      else: return 'Senior'

### 🔍 의문 5. "어린이 먼저" 구했다는데, 왜 어린이(Child) 생존율이 100%가 아니라 56%에 불과할까?
* **결론 (심슨의 역설):** 객실 등급이라는 거대한 변수가 통계를 왜곡하고 있었다.
  * pclass와 age_group을 3중 교차 표 (pd.crosstab)로 쪼개 분석한 결과:
    * **1, 2등석 어린이 생존율:** 거의 100%에 수렴 (대부분 구조 성공)
    * **3등석 어린이 생존율:** 약 30~40%대로 수직 추락
  * 전체 데이터를 합쳐놓았을 때는 3등석 어린이의 압도적인 수와 낮은 생존율이 전체 평균을 깎아내려 "어린이도 생각보다 못 살았네"라는 착시를 주었던 것(심슨의 역설, Simpson's Paradox)을 데이터로 완벽하게 입증했다.

## 🛠️ 새로 배운 판다스(Pandas) 치트키

1. **pd.crosstab(index, columns, normalize)**
   * 범주형 데이터 2개를 교차시켜 빈도수 표(피벗 테이블)를 만드는 강력한 함수.
   * normalize='index' 옵션으로 가로행 기준 백분율(%) 비율을 구하는 법을 마스터했다.
2. **DataFrame.reindex(list)**
   * 뒤죽박죽으로 정렬되는 인덱스 순서를 내가 원하는 순서(예: Child -> Young -> Middle...)로 강제 재배치하는 방법을 터득했다.
3. **df[col].apply(function)**
   * 시리즈의 모든 행에 특정 함수를 위에서 아래로 순차 적용하여 새로운 파생 변수 컬럼을 아주 쉽게 매핑하는 테크닉을 익혔다.
